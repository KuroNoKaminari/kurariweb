Trodo Engine

Description

A custom graphics engine built from scratch in C++ and OpenGL.

Rendering, data architecture, physics, scripting and networking, all designed and implemented at a low level without relying on an existing engine. Includes a Unity/Unreal-style editor with Hierarchy, Inspector, Content Browser and a real-time Viewport with transform gizmos.

Key Systems

Archetype-based ECS (DOTS-style) for high-performance data layout.

Deferred + Forward rendering pipeline with PBR, dynamic shadows and editable HDRI Skybox.

Node-based Material Editor, inspired by Unreal Engine 5.

C# scripting via Mono with hot-reload.

Custom physics engine: rigidbodies, box/sphere/capsule colliders and triggers with C# events.

Native client-server networking, showcased in a multiplayer Slither.io-style demo with live leaderboard and in-game chat.

Language

C++

Library

OpenGL

Tools

Mono
